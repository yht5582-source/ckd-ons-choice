# CKD Stage 5／5D 口服營養品智慧匹配與跨品牌組合系統

一套以繁體中文呈現的臨床營養決策支援工具，協助醫師、營養師、護理師與腎臟病衛教師，依第五期慢性腎臟病患者的透析狀態、身體測量、進食情形及檢驗數據，快速估算營養需求、辨識營養風險，並比較不同口服營養補充品（Oral Nutritional Supplements, ONS）。

> **重要聲明：** 本工具僅供臨床評估、衛教與討論使用，不是診斷工具，也不能取代醫師或營養師的個別化評估與處方。產品配方、容量、營養標示及供應狀況可能變動，使用前應再次查核原廠最新資料。

## 主要功能

- 依年齡、性別、身高與體重計算 BMI、理想體重（IBW）。
- 依未透析、血液透析或腹膜透析狀態，估算每日熱量與蛋白質需求範圍。
- 整合食慾下降、體重減輕、糖尿病與 HbA1c 等臨床資訊。
- 納入 Albumin、Na、K、Ca、P 等檢驗數據，產生營養警訊與評估提示。
- 依透析狀態與食慾，優先排列液狀濃縮或粉狀沖泡配方。
- 平行比較不同品牌產品的熱量、蛋白質、鈉、鉀與磷含量。
- 提供未透析與透析患者的跨品牌組合示例。
- 內建兩組示範個案，可快速了解操作流程。
- 支援重置資料以及列印／匯出評估頁面。

## 適用情境

| 患者類型 | 系統預設熱量 | 系統預設蛋白質 |
|---|---:|---:|
| CKD Stage 5，尚未透析（NDD） | 30–35 kcal/kg IBW/day | 0.6–0.8 g/kg IBW/day |
| CKD Stage 5D，血液透析（HD） | 30–35 kcal/kg IBW/day | 1.2–1.4 g/kg IBW/day |
| CKD Stage 5D，腹膜透析（PD） | 30–35 kcal/kg IBW/day | 1.2–1.3 g/kg IBW/day |

以上為目前程式內建的起始估算值。實際需求應依年齡、活動量、乾體重、殘餘腎功能、透析充分性、發炎或感染、分解代謝、糖尿病控制、腹膜透析葡萄糖吸收及營養狀態個別調整。

## 輸入資料

使用者可輸入或選擇：

- 年齡、性別、身高、實際體重
- 透析狀態：未透析、血液透析、腹膜透析
- 食慾與近期體重變化
- 糖尿病狀態與 HbA1c
- Albumin、Na、K、Ca、P

## 系統輸出

完成輸入後，頁面會即時計算並顯示：

1. BMI 與理想體重
2. 每日熱量及蛋白質需求範圍
3. 臨床營養警訊
4. 建議優先劑型
5. 適用產品的多品牌比較
6. 跨品牌組合示例

## 使用方法

1. 開啟 `index.html`。
2. 輸入患者基本資料。
3. 選擇透析狀態及食慾／體重趨勢。
4. 填入糖尿病狀態與最新檢驗值。
5. 查看系統即時產生的需求估算、警訊與產品比較。
6. 由醫療團隊依完整病史、飲食紀錄、藥物與臨床狀態判斷是否採用。
7. 如需留存，可使用「列印／匯出評估表」。

## 本機執行

本專案沒有後端服務或建置流程，可直接以瀏覽器開啟 `index.html`。若瀏覽器限制本機功能，也可在專案目錄啟動簡易伺服器：

```bash
python -m http.server 8000
```

再前往：

```text
http://localhost:8000
```

## GitHub Pages 部署

1. 進入 repository 的 **Settings → Pages**。
2. 在 **Build and deployment** 選擇由分支部署。
3. 選擇 `main` 分支及根目錄 `/`。
4. 儲存後等待 GitHub Pages 完成部署。

## 產品資料維護

產品資料位於 `index.html` 的 `PRODUCTS` 陣列。更新產品時，應逐項核對：

- 品牌與產品名稱
- 適用族群（未透析或透析）
- 劑型與每份容量
- 每份熱量及蛋白質
- 鈉、鉀、磷含量
- 配方特色與臨床定位
- 資料來源與查核日期

產品改版或營養標示異動後，應同步修正所有比較、警訊與組合計算內容，避免顯示過期數據。

## 隱私與資料處理

本工具為純前端網頁，現有程式只在使用者當前瀏覽器頁面中進行計算，未設計將輸入資料上傳至伺服器或永久儲存。即使如此，臨床使用時仍不建議輸入姓名、身分證字號、病歷號等可識別個人的資料。

## 臨床限制

- Albumin 會受發炎、感染、肝功能與體液狀態影響，不能單獨作為營養不良診斷。
- 單次 Na、K、Ca、P 數值不能取代趨勢判讀、飲食評估與透析處方檢視。
- 系統未完整計算正餐、點心、透析液吸收量及所有營養品合計的每日攝取量。
- 系統未處理吞嚥障礙、液體限制、過敏、腸胃耐受性、藥物交互作用或磷結合劑劑量。
- 任何高血鉀、嚴重高血磷、快速體重下降、低血糖、呼吸困難或其他急性異常，均應優先接受正式醫療評估。
- ONS 的選擇與用量應由醫師及營養師依個案狀況共同決定。
